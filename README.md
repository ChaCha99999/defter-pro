## Defterim Pro README

# Defterim Pro

Defterim Pro, kişisel finans, cari hesap ve işlem takibi için geliştirilen modern bir web uygulamasıdır.

Gelir-gider takibi, kategori yönetimi, notlar ve yaklaşan işlemler gibi temel finans yönetimi ihtiyaçlarını sade bir arayüzle sunar.

## Özellikler

- Gelir-gider takibi
- Cari hesap yönetimi
- Kategori yönetimi
- Not ekleme ve takip
- Yaklaşan işlem takibi
- Kullanıcı dostu modern arayüz

## Kullanılan Teknolojiler

- React
- JavaScript
- HTML
- CSS
- LocalStorage

## Kurulum

```bash
git clone repo-linki
cd defterim-pro
npm install
